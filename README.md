# 🚀 TaskFlow — Agile Kanban Workspace

A modern, highly performant, and responsive Kanban Board web application built with **React**, **Vite**, and **Pure CSS**. Features custom glassmorphic UI design, persistent browser storage via **LocalStorage**, and smooth drag-and-drop task workflows powered by the native **HTML5 Drag and Drop API**.

---

## ✨ Features

- 🎯 **Native Drag and Drop:** Seamless task management using HTML5 Drag and Drop API with real-time visual drop feedback.
- 💾 **Persistent LocalStorage:** Tasks automatically persist in the browser's storage across page reloads.
- 🎨 **Glassmorphism UI:** Custom dark-themed layout built with pure CSS Variables, flexbox, and grid.
- ⚡ **Full CRUD Capabilities:** Create, read, status update, and delete tasks effortlessly.
- 📱 **Responsive Layout:** Responsive 3-column layout optimized for desktops, tablets, and mobile screens.

---

## 🛠️ Tech Stack

- **Frontend Library:** [React.js](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** Vanilla CSS (Flexbox, CSS Grid, Custom Variables)
- **State Management:** React React Hooks (`useState`, `useEffect`)
- **API:** HTML5 Drag and Drop API
